# 11회차 시작 자료

- 교육용 합성 배송 데이터입니다. **한 행은 출고 전 오전 9시에 점검한 주문 한 건**입니다.
- 본인 10회차 결과가 있으면 그대로 이어갑니다. 제공 파일은 이전 결과가 없을 때 사용합니다.

| 파일 | 내용 |
|---|---|
| `delivery_features_09.csv` | 1~10월 주문 12,000건. 원본 정보와 이전 수업에서 만든 파생변수 포함 |
| `delivery_predictions_10.csv` | 7~8월 2,400건에 대한 기존 네 모델의 참고 예측. 원본 열 포함 |
| `delivery_models_10.json` | 기존 네 모델을 복원할 입력 목록·전처리·설정·기간 |

## 주요 열

| 열 | 의미 |
|---|---|
| 주문ID | 주문을 구분하고 결과를 연결하는 값. 모델 입력에서 제외 |
| 점검기준일시 | 모델이 주문을 점검하는 날짜·시각. 기간 구분과 운영 화면 조회 기준 |
| 배송약속일 | 고객에게 약속한 배송 날짜 |
| 배송여유일수 | 점검 날짜에서 배송약속일까지 남은 날짜 수. 0이면 오늘까지 배송해야 함 |
| 주문후_경과시간 | 주문일부터 점검 시점까지 지난 시간. 단위는 시간 |
| 센터물량부하율 | 센터출고대기건수 ÷ 센터당일처리계획건수. 1.2는 120% |
| 점검요일 | 점검기준일시에서 구한 요일 |
| 재고확보상태 | 미확보 / 부분확보 / 확보완료 |
| 총중량_kg · 배송거리_km | 주문의 총중량(kg)과 배송거리(km) |
| 실제배송완료일 · 배송지연여부 | 배송 후 확인한 정답 정보. 완료 날짜가 약속 날짜를 넘기면 지연(1), 아니면 정상(0) |

- 입력은 숫자 8개·범주 7개이며 전체 목록은 JSON에 있습니다. 실제배송완료일·배송지연여부는 입력에서 제외합니다.
- 참고 예측의 `_확률`은 0~1 값, `_예측`은 50% 이상이면 1, 미만이면 0입니다.
- 기간별로 1~6월 7,200건 / 7~8월 2,400건 / 9~10월 2,400건입니다. 이번 역할은 실습 단계에서 안내합니다.
- 모든 날짜의 모든 주문을 모은 자료는 아닙니다. 운영 화면의 주문 수는 제공된 자료 범위의 건수입니다.
- 미래 정보처럼 보이는 실제 결과 열은 과거 평가용으로만 사용합니다. 9~10월 운영용 CSV와 메인 화면에는 넣지 않습니다.
- 참고 결과는 기존 환경에서 실행한 예시입니다. 복원한 모델을 사용할 때는 해당 모델의 예측을 비교와 운영에 일관되게 사용합니다.
