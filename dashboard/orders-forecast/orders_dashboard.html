매장 주문량 예측 검토

실제 지역명을 사용한 교육용 가상 매장 자료입니다. 이 화면은 과거 기간을 예측해 실제와 비교한 결과입니다.

매장·요일별 주문 현황

읽는 법
  • 매장 차이가 가장 큽니다. 같은 요일끼리 비교해도 판교가 수원의 약 2배입니다.
  • 모든 매장이 주말에 늘어납니다. 매장 평균 대비 월요일은 약 7% 낮고 토요일은 약 11% 높습니다.
  • 요일 효과의 크기는 매장마다 다릅니다. 월요일과 토요일 차이가 수원은 66건, 잠실은 35건입니다.
매장별 평균
  • 판교 > 강남 > 잠실 > 양재 > 수원 순서입니다.
  • 영업시간도 매장마다 범위가 다릅니다. 판교·강남은 11~13시간, 수원·양재는 9~11시간이라 매장 차이와 영업시간 차이가 섞여 있습니다.

이 선택은 이 영역(평가 기간 예측 결과)에만 적용됩니다. 학습 기간 현황과 회귀계수는 바뀌지 않습니다.

날짜별 실제·예측 주문건수

예측 차이가 큰 기록 (절대값 상위 10)

예측오차 = 실제 − 예측. 양수는 실제보다 적게 예측, 음수는 실제보다 많이 예측한 경우입니다. 예측값은 소수 첫째 자리로 표시하고 계산에는 반올림 전 값을 씁니다.

주요 해석
  • 영업예정시간 1시간 증가: 다른 조건이 같으면 예측이 약 21.6건 늘어납니다.
  • 할인율 0% → 10%: 2.3건 × 10 = 약 23.0건 늘어납니다.
  • 요일: 기준은 금요일입니다. 토요일은 +23.8건, 월요일은 −29.4건이라 월요일과 토요일의 차이는 약 53건입니다.
  • 매장: 기준은 강남역입니다. 판교는 +62.1건, 수원은 −104.5건입니다.

계수는 다른 입력 조건을 같게 두었을 때 모델 예측값이 달라지는 정도입니다. 실제 할인·영업시간 변경의 효과가 입증된 것은 아닙니다.
