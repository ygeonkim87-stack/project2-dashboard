4. 모델 검토 의견

  • 고려한 업무 상황: 하루 점검 인력이 제한된 배송 운영팀이 정해진 인원으로 지연 위험 주문을 최대한 찾아 사전 조치해야 하는 상황을 가정했습니다.
  • 비교한 모델: 의사결정나무 깊이 4·깊이 6, 랜덤포레스트, 가중치 적용 랜덤포레스트를 같은 7~8월 평가 주문 2,400건과 50% 기준으로 비교했습니다. 랜덤포레스트는 소수만 확실하게 고르고, 가중치 적용 모델은 지연을 많이 찾는 대신 점검량이 크게 늘었습니다.
  • 선택한 모델: 의사결정나무·깊이 6을 선택했습니다.
  • 판단 근거: 깊이 6은 점검 215건으로 지연 132건을 찾아 깊이 4(169건 점검, 103건)보다 29건을 더 찾으면서 정밀도는 61.40%로 비슷하게 유지했습니다. 가중치 적용 모델은 재현율 75.24%로 더 많이 찾지만 871건을 점검해야 하고 그중 558건이 정상이라 제한된 인력에는 부담이 큽니다.
  • 감수할 점·추가 확인 사항: 실제 지연의 68.27%(284건)는 여전히 놓치므로, 고객 영향이 큰 주문은 별도 기준을 두는 것이 필요합니다. 적용 전에 하루 처리 가능 점검 건수, 주문당 점검 시간, 센터·날짜별 물량 편차(추가 2)를 확인해야 합니다.

지연을 놓치는 부담이 더 큰 상황이라면 가중치 적용 랜덤포레스트(놓친 지연 103건)나 class_weight {0:1, 1:3} 모델(추가 3)을 우선 검토합니다.
