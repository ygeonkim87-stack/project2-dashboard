Project2 대시보드

데이터 분석 실습 결과를 주제별로 모았습니다.

입고검사 품질 분석 카페 브랜드 매장 분석

입고검사 데이터로 협력사 품질과 생산조건을 살펴봅니다.

02회차

입고검사 EDA 대시보드

협력사·작업조별 검사 결과와 불량률을 탐색합니다.

 03회차

협력사 품질 검토

협력사별 치수 분포, A사 주차별 비교, 라인·작업조 히트맵과 검토 의견을 정리합니다.

 04회차

협력사 생산조건 검토

가공시간·누적가공수와 치수의 관계, 협력사·설비별 비교를 확인합니다.

카페 브랜드 5개 매장의 일일 주문 데이터로 다음 날 주문건수를 예측합니다. 실제 지역명을 사용한 교육용 가상 매장 자료입니다.

05회차

매장 주문량 예측 검토

매장·요일별 주문 현황, 실제·예측 비교와 회귀계수 해석, 강남역매장 심화 검토(광복절 주 상세·영업시간 조건별 예측·강남·판교 비교)를 한 화면에서 확인합니다.

 06회차

주문량 예측 모델 평가

매장별 평균·첫 회귀·정보추가·행사정보 추가 네 방법의 MAE·RMSE 비교, 매장별 오차 방향 해석, 2D·3D·4D 그래프를 확인합니다.
