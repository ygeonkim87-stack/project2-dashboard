  • 영업시간 범위도 매장마다 달라(판교·강남 11~13, 수원·양재 9~11시간) 두 효과가 섞여 있습니다.

실제·예측 비교

매장 선택
선택은 이 영역(평가 기간 예측 결과)의 그래프·요약 수치·오차 기록·해석에 적용됩니다. 학습 기간 현황과 회귀계수는 바뀌지 않으며, 모델은 다시 학습하지 않고 처음 만든 모델의 예측값을 그대로 씁니다.

예측오차가 큰 기록 · 절대값 상위 10

예측오차 = 실제 − 예측. 양수는 실제보다 적게 예측, 음수는 실제보다 많게 예측한 경우입니다. 예측값은 소수 첫째 자리로 표시하고 계산에는 반올림 전 값을 씁니다.

주요 해석
  • 영업예정시간 1시간 증가: 다른 조건이 같으면 예측이 약 21.6건 늘어납니다.
  • 할인율 0% → 10%: 2.3건 × 10 = 약 23.0건 늘어납니다.
  • 요일(기준 금요일): 토 +23.8건, 월 −29.4건 → 월↔토 약 53건 차이
  • 매장(기준 강남): 판교 +62.1건, 수원 −104.5건

계수는 다른 입력 조건을 같게 두었을 때 모델 예측값이 달라지는 정도입니다. 실제 할인·영업시간 변경의 효과가 입증된 것은 아닙니다.

① 주간 상세 검토 · 강남역매장

확인할 날짜
  • 8/15(토, 광복절): 실제 265건, 예측 393.8건으로 128.8건 많게 예측했습니다. 평가 기간 강남에서 가장 크게 빗나간 날입니다. 이번 모델은 공휴일여부를 입력에 넣지 않아 평범한 토요일처럼 예측했습니다. 학습 기간 강남의 공휴일 평균(378.5건)은 평일(369.7건)과 비슷했으므로, 이날은 공휴일이라는 것만으로 설명되지 않는 이례적인 날일 수 있습니다.
  • 8/11(화): 실제 433건, 예측 323.4건으로 109.6건 적게 예측했습니다. 영업 11시간, 할인 없음이라 모델이 낮게 봤지만 실제 주문은 많았습니다.

계속 한쪽으로 틀린 주가 아닙니다. 주 초반(8/10 +77.4, 8/11 +109.6)은 적게, 주말(8/15 −128.8, 8/16 −42.4)은 많게 예측해 방향이 바뀌었습니다. 수~금(8/12~14)은 ±21건 안쪽으로 비교적 잘 맞았습니다.

③ 두 매장 비교 · 강남역매장 vs 판교역매장

해석
  • 규모와 오차를 구분해서 보세요. 판교의 평균 절대오차(47.1건)가 강남(36.1건)보다 크지만, 주문 규모 대비 오차(MAPE)는 판교 9.3%, 강남 10.3%로 비슷합니다. 판교 오차가 큰 것은 주로 매장이 크기 때문입니다.
  • 빗나가는 방향은 반대입니다. 강남은 평가 기간 실제 평균(356.8건)이 학습 기간(370.2건)보다 줄어 많게 예측했고, 판교는 431.4건에서 474.3건으로 늘어 적게 예측했습니다.
  • 판교의 차이는 시간이 갈수록 커집니다. 판교는 6월 +16.5건에서 8월 +65.6건으로 늘었습니다. 강남은 6월 −27.6건에서 8월 −0.7건으로 줄었습니다. 매장별 추세를 반영하지 못하는 첫 모델의 한계로 보입니다.

두 매장 모두 같은 기간(2026-06~08)과 같은 단위(건)이며, 위 선그래프 두 개는 세로축 범위를 같게 맞췄습니다.
